GitHub Pages 零成本上线与谷歌收录三步法

1. 创建 GitHub 仓库并上传代码

在 GitHub.com 新建公开仓库，直接将本代码保存为 index.html 上传至仓库根目录。

2. 开启 GitHub Pages 免费公网访问

进入仓库 Settings -> 左侧 Pages -> Build and deployment 选择 Deploy from a branch (main / root)，点击 Save 即可获得全球公网链接。

3. 提交 Google Search Console 让谷歌自动抓取

打开 Google Search Console 添加你的网址，Google 爬虫会依据页面包含的精准 HS 编码关键词自动收录排名。
